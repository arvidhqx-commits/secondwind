# SecondWind
Downed state instead of instant death for Paper 1.21+/26.x (runtime-tested on Paper 1.21.11, 26.2 and 26.3 — 63 assertions against the shipped jar). When a hit would kill you, you go down instead: slowed, glowing, bleeding out on a timer. A teammate sneaks next to you to revive; attackers can finish you off. Fully configurable (timers, health values, execute rules, per-world), MiniMessage texts, zero dependencies. `/sw giveup` to respawn early.
